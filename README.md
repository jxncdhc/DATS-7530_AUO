# DATS 7530: Computing for Data Science

Course materials for **DATS 7530 Computing for Data Science** (Augusta University Online).
Instructor: Haocheng Ding, Department of Biostatistics, Data Science, and Epidemiology, Augusta University.

This site hosts the lecture slides, lab code, and reading links for each module.
Lecture videos, assignments, and submissions are in D2L.

## Modules

| Module | Title | Weeks |
|---|---|---|
| [Module 1](module1/) | Getting Started with R: Data Types and Data I/O | 1–2 |
| Module 2 | Programming in R: Control Flow, Functions, and Loop Functions | 3–4 |
| Module 3 | Data Manipulation and Efficient R Programming | 5–6 |
| Module 4 | Introduction to Linux and the Shell | 7–8 |
| Module 5 | Linux File System, Permissions, and Text Processing | 9–10 |
| Module 6 | Bash Scripting and Running R from the Command Line | 11–12 |
| Module 7 | SQL Fundamentals | 13 |
| Module 8 | Using SQL with R | 14 |
