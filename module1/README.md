# Module 1: Getting Started with R: Data Types and Data I/O

**Weeks 1–2** · [Back to course home](../)

## Overview

This module introduces R, the statistical programming language used throughout the first half
of the course. You will install R and RStudio, learn how the R system is organized, work with
R's basic data types and objects, and read and write data in several formats.

## Learning Objectives

By the end of this module, you will be able to:

1. Describe the history, design, and main features of the R system.
2. Install R and RStudio and operate the R console to run code and scripts.
3. Explain R's basic data types and objects, including vectors, matrices, lists, factors, missing values, and data frames.
4. Use R functions to read and write data in text and binary formats.
